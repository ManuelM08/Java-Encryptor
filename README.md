# 🔐 Java Encryptor

A lightweight and efficient text encryption system built with Java. This tool uses a randomized substitution cipher to secure messages while maintaining key persistence across sessions.

## ✨ Features
- **Key Persistence**: Keys are automatically saved to a `.properties` file in the `saves/` directory.
- **Randomized Generation**: Create a secure, randomized character mapping with a single command.
- **Extended Support**: Handles uppercase/lowercase letters, numbers, and special symbols.
- **Input Validation**: Built-in checks to prevent duplicate mappings or unsupported characters.
